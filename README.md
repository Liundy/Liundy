# A股看盘台 V1

一个面向个人 A 股交易者的看盘界面原型。视觉方向参考专业量化/交易终端的信息密度，但不复制第三方站点代码或品牌。

## V1 已包含

- 指数与全市场成交概览
- 自选股列表与切换
- K 线视觉原型与周期切换
- 板块强弱榜
- 市场情绪、涨跌家数、涨停梯队
- 盘中信号与个人交易观察
- 桌面/移动端响应式布局
- 模拟行情刷新

> 重要：当前所有行情数字均为演示数据，不能用于真实交易决策。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。
